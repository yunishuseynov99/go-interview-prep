# Мой ответ на собеседовании: «Что такое Closure?»

**Замыкание** — это **анонимная функция**, которая ссылается на переменные, объявленные вне её собственного тела (в окружающей области видимости).

Ключевая особенность: функция **«захватывает» (closes over)** эти переменные. Это значит, что она получает доступ к самим переменным, а не к их копиям. Даже если внешняя функция завершила работу, переменные продолжают жить внутри замыкания.

### 1. Как это выглядит (Пример State)

Самый классический пример — генератор или счетчик. Мы создаем функцию, которая хранит состояние внутри себя, без использования глобальных переменных.

```go
func adder() func(int) int {
    sum := 0 // Переменная sum "захвачена"
    return func(x int) int {
        sum += x
        return sum
    }
}

func main() {
    pos, neg := adder(), adder()
    
    fmt.Println(pos(1)) // 1 (sum=1)
    fmt.Println(pos(2)) // 3 (sum=3)
    
    fmt.Println(neg(-2)) // -2 (у neg своя копия sum)
}
```
Здесь `sum` не уничтожается после выхода из `adder()`, потому что анонимная функция удерживает ссылку на неё.

---

### 2. Как это работает внутри (Under the hood)

Для компилятора Go функция — это не просто указатель на код. Это **Function Value** (функциональное значение).

Технически замыкание — это структура, содержащая два указателя:
1.  **Указатель на код функции** (инструкции процессора).
2.  **Указатель на контекст (Environment)** — область памяти, где лежат захваченные переменные.

**Важный момент про память (Escape Analysis):**
Поскольку переменная (`sum` из примера выше) должна жить дольше, чем функция, которая её создала, компилятор Go выполняет **Escape Analysis**.
Он видит, что на переменную есть ссылка из возвращаемой функции, и переносит эту переменную **со стека в кучу (Heap)**. Это цена, которую мы платим за магию замыканий (аллокация).

### 3. Где это применяется (Use Cases)

1.  **Middleware в HTTP:**
    Мы оборачиваем один `http.Handler` в другой, захватывая параметры (логгер, таймаут) или сам следующий хендлер.
    ```go
    func WithLogging(next http.Handler) http.Handler {
        return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
            log.Println("Request started") // Замыкание
            next.ServeHTTP(w, r)           // Захват переменной next
        })
    }
    ```

2.  **Сортировка:**
    Использование `sort.Slice`, где мы передаем функцию сравнения, которая захватывает сортируемый слайс.

3.  **Goroutines и Worker Pools:**
    Запуск фоновых задач с передачей контекста.

### 4. Главный подводный камень (Loop Variables)

Это классический вопрос на собеседованиях.

**До Go 1.22:**
Переменная цикла была одна на все итерации. Если запустить горутину внутри цикла, используя эту переменную, все горутины могли напечатать последнее значение.

```go
// СТАРЫЙ Go (до 1.22)
for i := 0; i < 3; i++ {
    go func() {
        fmt.Println(i) // ОШИБКА: Скорее всего выведет "3, 3, 3"
    }()
}
```
*Лечение:* Либо передавать аргумент в функцию `go func(val int){...}(i)`, либо создавать теневую копию `i := i`.

**В Go 1.22+:**
Это поведение исправили. Теперь переменная цикла создается заново для каждой итерации, и замыкание захватывает "свой" экземпляр переменной. Код выше теперь выведет `0, 1, 2` (в случайном порядке).

Однако знать про старое поведение все равно нужно, так как в легаси-коде (или если в `go.mod` стоит старая версия) это может выстрелить.

---

### Резюме

> **Closure** — это функция + её контекст (захваченные переменные).
> Она работает по ссылке (меняет оригинал переменной).
> Переменные, захваченные замыканием, часто "убегают" в кучу (Heap Allocation).
> Это основной инструмент для написания Middleware и асинхронного кода.
